# 馆店试销流水

采购与仓配交接的粒度为馆店、商品和营业时段。第 70 日附近是新商品启动期，交接包含连续营业记录及报表日期。 数据全部为合成业务记录。文件使用 UTF-8 JSON，时间均为北京时间，货币如无单独说明均为人民币分。

## 查阅交接数据

使用 Python 3.11 标准库。在仓库根目录运行 `python3 inspect_delivery.py` 查看交接文件和行数，或在后面加文件名（含 `.json`）查看该文件的第一条记录。这个入口仅供查阅交接资料。

## 数据约定

- `stores.json` 馆店及陈列单位容量。
- `items.json` 商品、类目及价格带。
- `availability.json` 营业时段及观察状态。相同 block 可能有补报，known 为源账到达时点，较晚有效记录更正该时段。
- `sales.json` 同一时段的售出件数。未给销售行的完整可售时段为零售出。
- `warehouse.json` 到货批次的总箱数、装箱量、接收范围和最早可发日，已确认调拨从该总箱数中占用。
- `lanes.json` 仓至门店的日历日运输天数。
- `display_floor.json` 门店按销售周承诺的最低上架量。
- `dispatches.json` 既有调拨记录，区分预计和实际到馆。
- `returns.json` 退回与复检可售分别记录，cleared 为空代表还没有可售确认。
- `cycles.json` 历次发行日期及所预测的销售周，含成熟后验记录。

## 检查资料

运行 `python3 -m unittest discover -s tests -v`。检查会读取当前交接文件，核对该业务所需的关键原始证据是否齐备。
